# قياس وتمركز Dynamic Island على Windows

## قاعدة الإحداثيات

تُقاس مواضع الجزيرة ومستطيلات الشاشة بالبكسل الفيزيائي. عند الإقلاع وبعد كل انتقال مستقر ترسل صفحة الجزيرة مستطيل الكبسولة المرئي وارتفاع مرحلة الخمول. يقرأ Rust مستطيل النافذة ومساحة عميل WebView والشاشة الأقرب عبر `MonitorFromWindow` و`GetMonitorInfoW`، ويسجل `rcMonitor` و`rcWork` ومقياس Tauri وDPI الخاص بالنافذة.

تبقى الأبعاد المرئية كما هي: مرحلة الخمول 38 CSS px، وكبسولة الخمول 44×24 CSS px بنصف قطر 12px، ووضع الموسيقى مستطيل 112×24 CSS px بنصف قطر 11px؛ يترك ذلك ضلعًا مستقيمًا قصيرًا مقداره 2 CSS px بين الانحناءين، بدل شكل الحبة الكاملة أو الزاوية الحادة. موضع أعلى جسم الخمول 7px ومركزه عند 19px. تضيف حاوية WebView هامشًا شفافًا غير مرئي مقداره 2 CSS px حول الرسم، لذلك تكون نافذة الإقلاع 48×42 بدلًا من تغيير شكل الكبسولة أو تصغيرها. يسترد JavaScript مساحة الرسم بطرح الهامش، وتضيف دالة موحدة الهامش إلى كل قياس يرسله إلى Windows.

تتغير ارتفاعات الحالة الموسعة مع معامل الملاءمة وإزاحة الارتكاز؛ لذلك يقبل Rust مجالًا محدودًا من المقاسات التي تنتجها الواجهة بدل قائمة ارتفاعات ثابتة. يشمل الارتفاع هامش بكسل للحساب وهامش النافذة، وتُسجّل رسالة الخطأ المقاس الفعلي إذا خرج عن الحدود. يعود وضع التلاوة الكاملة إلى 384×210 CSS px، وبطاقة الصلاة 400×170، ويبقى وضع الموسيقى مستطيلًا بحواف ناعمة. تظل مرساة الخمول ثابتة خلال النابض، ويُصحح `SetWindowPos` والقياس اللاحق الإحداثيات ضمن سماحية نصف بكسل فيزيائي.

نافذة الجزيرة نافذة شفافة مستقلة فقط؛ لا تُنشأ نافذة نظامية إضافية ولا تتغير مساحة العمل أو مواضع نوافذ التطبيقات الأخرى. في `idle` و`compact` توسّع منطقة Windows الأصلية ببكسلين فيزيائيين حول مستطيل الرسم المستدير، كي لا تمر حافة القص عبر بكسلات التنعيم الجزئية. تبقى النقاط البعيدة عن شكل الجزيرة خارج منطقة النافذة وتصل نقراتها إلى التطبيقات التي تحتها؛ عند التوسيع تزال المنطقة ويعود مستطيل النافذة الكامل.

## سجل التشخيص

تُكتب القياسات بصيغة JSON Lines إلى `app_config_dir()/island-geometry.jsonl`. يحتفظ السجل بإحداثيات `rcMonitor` و`rcWork`، ومركز الارتكاز المحسوب من أصل الشاشة، ومركز الكبسولة قبل التصحيح وبعده، وعدد محاولات التصحيح. يدوّر السجل بعد تجاوزه 4 MiB. ينسخ خيار صينية النظام السجل إلى مجلد التنزيلات ليمكن إرفاقه عند ظهور اختلاف على جهاز المستخدم.

## تحقق Windows

يشغّل CI النسخة التنفيذية الناتجة على Windows ويتحقق من بقاء كبسولة الخمول 44×24 CSS px وهامش الرسم الشفاف. يبدأ الاختبار بمتغير بيئة مؤقت للعملية فقط؛ وعند جاهزية الجزيرة يرسل Rust حالة مشغل اصطناعية عبر حدث التطبيق المعتاد، ثم يعيدها إلى الخمول بعد الاختبارات. لا يُفتح منفذ CDP ولا تُكتب سياسة في سجل Windows، ولا يبقى إعداد بعد إغلاق التطبيق. يلتقط CI الشاشة الفعلية لوضع الموسيقى 112×24، ويفحص بكسلات الزوايا الأربع: الخلفية خارج الانحناء، السطح الداكن داخله، وبكسلات الانتقال التي تثبت التنعيم؛ فقياس CSS وحده لا يكفي. بعد ذلك ينقر فعليًا على الموسيقى لفتح المشغل الكامل 384×210 ويتحقق من خلوص أسفله وثبات مرساته، ومن وصول النقرات خارج الشكل وعند زاويته إلى النافذة الخلفية. ثم يختبر بطاقة الصلاة والخمول. تُرفع اللقطات وسجل JSONL وملخص النتائج كـartifact؛ غياب سطح عرض أو فشل أي خطوة يعني فشل الاختبار ولا يُعامل التخطي على أنه نجاح.
