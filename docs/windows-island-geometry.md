# قياس وتمركز Dynamic Island على Windows

## قاعدة الإحداثيات

تُقاس مواضع الجزيرة ومستطيلات الشاشة بالبكسل الفيزيائي. عند الإقلاع وبعد كل انتقال مستقر ترسل صفحة الجزيرة مستطيل الكبسولة وارتفاع مرحلة الخمول الصغيرة. يقرأ Rust مستطيل النافذة ومساحة عميل WebView والشاشة الأقرب عبر `MonitorFromWindow` و`GetMonitorInfoW`، ويسجل `rcMonitor` و`rcWork` ومقياس Tauri وDPI الخاص بالنافذة.

في `idle` و`compact` يكون مركز جسم الجزيرة هدفًا أفقيًا في منتصف الشاشة ورأسيًا على ارتفاع نصف مرحلة CSS الصغيرة من `rcMonitor.top`؛ المرحلة 38 CSS px، والخمول 44×24 CSS px بنصف قطر 12px، والموسيقى 112×24 CSS px بنصف قطر 9px، فيكون موضع أعلى الجسم 7px. يطابق مقاس الخمول نسبة الصورة المرجعية، بينما يبقى وضع الموسيقى مستطيلًا بحواف مدوّرة لا كبسولة طويلة. يظل موضع الخمول مرساة الحالات طوال النابض، بينما تُحسب مساحة نافذة WebView للحالة الموسعة من ارتفاع الرسم مضافًا إليه إزاحة الارتكاز وبكسل CSS احتياطي للتقريب، حتى لا يُقصّ الأسفل. تعود حالة التلاوة الكاملة إلى 384×210 CSS px، ويُرفع ارتفاع بطاقة الصلاة إلى 170px كي يحتوي ارتفاع الرسم المحوّل. يحاذي كل من `SetWindowPos` والقياس اللاحق إحداثيات العرض الفعلية ضمن سماحية 0.5 بكسل فيزيائي. عند التوسيع يبقى أصل مساحة عميل النافذة عند أصل الشاشة الرأسي ومتمركزًا أفقيًا؛ يُنفذ التصحيح على خيط النافذة وبحد أقصى ثلاث محاولات.

نافذة الجزيرة نافذة شفافة مستقلة فقط؛ لا تُنشأ نافذة نظامية إضافية ولا تتغير مساحة العمل أو مواضع نوافذ التطبيقات الأخرى. في `idle` و`compact` يطابق Windows منطقة النافذة الأصلية حدود الجزيرة ونصف قطرها المرسل من الواجهة (12px للخمول و9px للموسيقى بعد احتساب مقياس الشاشة)، فتكون المساحة خارج الرسم غير موجودة في hit-test حتى في نوافذ عمليات أخرى؛ عند التوسع تزال المنطقة ويعود مستطيل النافذة الكامل.

## سجل التشخيص

تُكتب القياسات بصيغة JSON Lines إلى `app_config_dir()/island-geometry.jsonl`. يحتفظ السجل بإحداثيات `rcMonitor` و`rcWork`، ومركز الارتكاز المحسوب من أصل الشاشة، ومركز الكبسولة قبل التصحيح وبعده، وعدد محاولات التصحيح. يدوّر السجل بعد تجاوزه 4 MiB. ينسخ خيار صينية النظام السجل إلى مجلد التنزيلات ليمكن إرفاقه عند ظهور اختلاف على جهاز المستخدم.

## تحقق Windows

يشغّل CI النسخة التنفيذية الناتجة على Windows، ينتظر قياس حالة الخمول، ويتحقق من تطابق مركز جسم الجزيرة مع أصل الشاشة ضمن نصف بكسل. يلتقط صورة للجزيرة ويرسل نقرة فعلية إلى مركزها، ثم يتحقق من فتح حالة الصلاة ومن توسع نافذة Tauri. يسجل التطبيق مدى موضع أعلى الجزيرة عبر إطارات الحركة؛ يفشل smoke إذا تحرك بأكثر من 0.75 CSS px. يرسل نقرة ثانية للتحقق من العودة إلى الخمول وبقاء التمركز، ثم يتأكد أن النقر في زاوية الجزيرة المستديرة وخارج حافتها يمر إلى النافذة التي تحتها. يرفع الصور وسجل JSONL وملخص النتيجة كـartifact. غياب سطح عرض تفاعلي أو تعذر أي خطوة يجعل الاختبار يفشل؛ لا يُعامل التخطي على أنه نجاح.
